    Из чего складывается платёж

    Обязательные платежи без рыночных расходов.

    Возраст: скачок на трёх годах

    С трёх лет сбор за регистрацию — 500 МРП (2,16 млн тг) вместо 50, пошлина по ДТ переходит на ставки для б/у. По ПТД старше 5 лет ставка выше — второй скачок.

    Цена: фиксированные платежи бьют по дешёвым машинам

    Утильсбор, сбор за регистрацию и минимумы пошлины в €/см³ не зависят от цены.

    ПТД или ДТ для физлица

    Разница «ПТД минус ДТ», млн тг. Синий — ПТД дешевле, красный — дороже. По ДТ машина выпускается условно по ставкам ВТО и обращается только в РК. С 26.09.2026 ЭПТС по ПТД оформляют только на машины до 5 лет (приказ МПС № 474, по СМИ).

    Тип двигателя

    Маршрут «Третьи страны · ДТ». Электромобиль и гибрид с более мощным электромотором — пошлина 0% по перечню ВТО и без утильсбора.

    Утильсбор: Россия и Беларусь против остальных

    Легковые M1, 50 МРП × коэффициент. Коэффициент 2 для ввоза из РФ и РБ действует с 07–08.05.2026 (приказ МЭПР № 54).

    База ставок

    Каждая ставка — с нормой и уровнем достоверности: А — текст акта, Б — разъяснение госоргана, В — СМИ, Г — рыночная оценка, Д — спорно. Щёлкните строку, чтобы раскрыть подробности.
